# MANU Roblox Launcher (Android)

Masterstrap-style FastFlag manager + launcher.

## Features
- FastFlag editor (JSON)
- Presets: FPS 120, Potato, Gray Sky, Low GFX
- Real **Root** + **Shizuku** write to `/data/local/tmp/ClientAppSettings.json`
- Launch Roblox one-tap
- GitHub Actions → ready APK

## Requirements
- Android 8.0+ (API 26)
- For flags: Root **or** Shizuku (shizuku.rikka.app)

## Build APK via GitHub
1. Create repo, upload these files
2. Actions → **Build APK** → download artifact `manu-launcher-apk`

## Local build
Android Studio → Open → Sync → Build APK
